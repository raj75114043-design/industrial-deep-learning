# Runbook

| Signal | First checks | Action |
|---|---|---|
| Dissolution "unfamiliar conditions" | New supplier, site or parameter outside the historical range? | Hold the batch for the lab result; add it to training once tested |
| P(below Q) ≥ 0.2 | Lubrication time, hardness, API particle size | Lab test before release; investigate per the OOS SOP if it fails |
| Camera drift alarm | Lighting, focus, lens cleanliness | Fix the camera; if the camera is changed permanently, label ≥ 500 images and run adaptation |
| Inspection false-reject rate rising | Drift check, new product embossing | Re-calibrate τ on fresh validation images |
| Punch RUL alarm | Upcoming changeover, spare tooling | Plan the punch change at the next changeover |
